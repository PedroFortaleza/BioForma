# Prévia — Bio Forma Pilates e Fisioterapia

Landing page local criada como proposta visual para a Bio Forma, em Uberlândia.

Abra `index.html` no navegador para visualizar a página. A prévia é estática e não foi hospedada nem enviada a terceiros.

O visual se inspira no perfil público `@bioformapilatesefisio`, usando areia, creme, marrom e uma linguagem acolhedora. Os textos utilizam apenas serviços e informações verificáveis no perfil público: Pilates, fisioterapia, cuidado com gestantes e idosos, massoterapia, localização e WhatsApp.
